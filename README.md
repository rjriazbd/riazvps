# বাংলা OTT - বাংলাদেশের সেরা স্ট্রিমিং প্ল্যাটফর্ম 🎬

বাংলাদেশের নিজস্ব OTT (Over-The-Top) স্ট্রিমিং প্ল্যাটফর্ম। বাংলা সিনেমা, নাটক, ওয়েব সিরিজ এবং আরও অনেক কিছু এক জায়গায়।

## ✨ ফিচার সমূহ

- 🏠 **হোমপেজ** - হিরো ব্যানার স্লাইডার, ট্রেন্ডিং কন্টেন্ট, নতুন রিলিজ
- 🎬 **মুভি পেজ** - সব বাংলা মুভি জঁনরা অনুযায়ী ফিল্টার সহ
- 📺 **সিরিজ পেজ** - ওয়েব সিরিজ ব্রাউজ করুন
- 🎭 **নাটক পেজ** - বাংলা নাটক সমগ্র
- 🔍 **ব্রাউজ পেজ** - সার্চ, ফিল্টার, সর্টিং সহ
- ▶️ **ভিডিও প্লেয়ার** - ডিটেইল পেজ, এপিসোড লিস্ট, সম্পর্কিত কন্টেন্ট
- 🔐 **লগইন/রেজিস্টার** - ফোন/ইমেইল, সোশ্যাল লগইন (Google, Facebook)
- 💳 **সাবস্ক্রিপশন** - ৩টি প্ল্যান (ফ্রি, বেসিক ৯৯৳, প্রিমিয়াম ১৯৯৳)
- 📱 **রেসপন্সিভ ডিজাইন** - মোবাইল, ট্যাবলেট, ডেস্কটপ সাপোর্ট
- 🌙 **ডার্ক থিম** - চোখের জন্য আরামদায়ক

## 🛠️ টেকনোলজি

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel (recommended)

## 🚀 ইনস্টলেশন

```bash
# Clone the repository
git clone https://github.com/rjriazbd/riazvps.git
cd riazvps

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📁 প্রজেক্ট স্ট্রাকচার

```
src/
├── app/
│   ├── page.tsx          # হোমপেজ
│   ├── layout.tsx        # মূল লেআউট
│   ├── globals.css       # গ্লোবাল স্টাইল
│   ├── not-found.tsx     # ৪০৪ পেজ
│   ├── browse/           # ব্রাউজ পেজ
│   ├── movies/           # মুভি পেজ
│   ├── series/           # সিরিজ পেজ
│   ├── natok/            # নাটক পেজ
│   ├── watch/[id]/       # ভিডিও ডিটেইল/প্লেয়ার
│   ├── login/            # লগইন পেজ
│   ├── register/         # রেজিস্টার পেজ
│   └── pricing/          # সাবস্ক্রিপশন পেজ
├── components/
│   ├── Header.tsx        # নেভিগেশন হেডার
│   ├── Footer.tsx        # ফুটার
│   ├── HeroBanner.tsx    # হিরো স্লাইডার
│   ├── MovieCard.tsx     # মুভি কার্ড
│   └── ContentSection.tsx # কন্টেন্ট সেকশন
└── data/
    └── content.ts        # স্যাম্পল ডাটা
```
